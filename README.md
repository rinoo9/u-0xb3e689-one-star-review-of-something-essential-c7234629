# One-Star Review of Water

A deadpan one-star review of an everyday essential, written for the make.fun bounty "One-Star Review of Something Essential". The program `main.py` writes one single-line review — 123 characters — to `/output/entry.txt`:

> Water has no taste, no colour, and no smell, yet my glass is always empty and the bill still arrives every month. One star.

Run it with `python3 main.py`. Deterministic: no input, no network, no randomness — the same 123 characters every run.
