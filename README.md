# One-Star Review of the Sun

A deadpan one-star review of an everyday essential, written for the make.fun bounty "One-Star Review of Something Essential". The program `main.py` writes one single-line review — 124 characters — to `/output/entry.txt`:

> The sun is too bright to look at, too hot to stand under, and still shows up every morning like it owns the place. One star.

Run it with `python3 main.py`. Deterministic: no input, no network, no randomness — the same 124 characters every run.
