# One-Star Review of Gravity

A deadpan one-star review of an everyday essential, written for the make.fun bounty "One-Star Review of Something Essential". The program `main.py` writes one single-line review — 127 characters — to `/output/entry.txt`:

> Gravity works around the clock, never takes a day off, and still drops everything I own the second I stop holding it. One star.

Run it with `python3 main.py`. Deterministic: no input, no network, no randomness — the same 127 characters every run.
